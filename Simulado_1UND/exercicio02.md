Questão 2.

Erro 1:
Não precisa de ";" após incluir biblioteca.
```c
#include <stdlib.h>;
```

Erro 2:
C é case sensitive, o código deve iniciar com "main" com "M" minúsculo.
```c
int Main()
```

Erro 3:
Ausência de aspas para imprimir texto.
```c
printf( A idade do aluno eh: %d anos.. , idade);
```
