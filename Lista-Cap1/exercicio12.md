INSTRUÇÃO           | STATUS (C/I)   |   JUSTIFICATIVA
a) int a;             Correto            Declaração padrão para variável inteira.
b) float b;           Correto            Declaração padrão para variável com ponto flutuante.
c) double float c;    Incorreto          Double e float são tipos distintos de variável.
d) unsigned char d;   Correto            O "unsigned" permite aumentar a quantidade de números inteiros excluindo negativos.
e) unsigned e;        Correto            Trata como uma variável "unsigned int", retirando números negativos.
f) long float f;      Incorreto          O "C" não suporta essa combinação, o correto seria usar double.
g) long g;            Correto            Trata como uma variável "long int".
h) long double h;     Correto            É o tipo de ponto flutuante com a maior precisão disponível na linguagem C.
