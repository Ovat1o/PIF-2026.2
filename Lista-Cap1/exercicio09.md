Questão 09.

Saída exata:
```text
    
        "Primeiro programa"
```
O compilador do C interpreta as sequências de escape iniciadas por barra invertida combinadas com aspas simples como caracteres únicos de controle.

'\n' é interpretado como comando de quebra de linha.

'\t' insere um caractere de tabulação horizontal.

'\"' utiliza a barra invertida para tirar a restrição sintática, permitindo que o caractere de aspa seja impresso pelo %c, em vez de ser lido como delimitador de código.
