## 📖 Ementa
Este repositório explora a introdução a dois dos principais paradigmas de linguagem de programação: **imperativa** e **funcional**.

* **Linguagem C (Imperativa):** comandos de entrada e saída; estruturas de decisão e repetição; matrizes, strings e tipos de dados estruturados; subprogramas, arquivos, conjuntos, ponteiros; alocação dinâmica de memória; introdução à programação modular.
* **Linguagem Haskell (Funcional):** listas, tuplas, tipos, classes, polimorfismo, funções de alta ordem, recursão.

## ⚙️ Ferramentas Utilizadas
- **C:** Compilador GCC, IDE recomendada (VS Code, CLion, etc.)
- **Haskell:** GHC (Glasgow Haskell Compiler) e GHCi (REPL)
- **Ambiente:** AWS Academy
