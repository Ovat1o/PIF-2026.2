Questão 05.

Considerando `i = 1`, `j = 2`, `k = 3`, `n = 2`, `x = 3.3` e `y = 4.4`:

a) `i < j + 3` resulta em `1`, pois `1 < 5`.

b) `2 * i - 7 <= j - 8` resulta em `0`, pois `-5 <= -6` é falso.

c) `-x + y >= 2.0 * y` resulta em `0`, pois `1.1 >= 8.8` é falso.

d) `x == y` resulta em `0`, pois `3.3` é diferente de `4.4`.

e) `!(n - j)` resulta em `1`, pois `n - j` vale `0` e `!0` vale `1`.

f) `!n - j` tem valor numérico `-2`, pois `!2` vale `0` e `0 - 2 = -2`. Se usado como condição lógica, `-2` é considerado verdadeiro por ser diferente de zero.

g) `i && j && k` resulta em `1`, pois os três valores são diferentes de zero.

h) `i || j - 3 && k` resulta em `1`. O operador `&&` é avaliado antes de `||`; além disso, `i` já é verdadeiro.

i) `i < j && 2 >= k` resulta em `0`, pois a primeira comparação é verdadeira, mas `2 >= 3` é falsa.

j) `i == 2 || j == 4 || k == 5` resulta em `0`, pois todas as comparações são falsas.
